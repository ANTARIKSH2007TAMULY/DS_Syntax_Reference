Bootstrap Confidence Interval

Formula

Resample with replacement B times → compute statistic each → CI = [percentile(α/2), percentile(1−α/2)]

Full Syntax

from scipy import stats

rng = np.random.default_rng(seed=42)
data = (x,)  # tuple of samples
res = stats.bootstrap(data, np.mean, n_resamples=9999, confidence_level=0.95,
                      random_state=rng, method='percentile', vectorized=False,
                      paired=False, axis=0, batch=None)
res.confidence_interval  # .low, .high

Parameters

ParameterTypeDefaultMeaning
datasequence of arrays—Sample(s) to bootstrap
statisticcallable—Function computing statistic (e.g. np.mean)
n_resamplesint9999Number of bootstrap iterations
confidence_levelfloat0.95Confidence level
random_stateGenerator, intNoneRandom number generator
method{'percentile','basic','bca'}'BCa'CI construction method
vectorizedboolFalseVectorize statistic over resamples
pairedboolFalsePaired bootstrap
axisint0Axis of samples
batchint, optionalNoneBatch size for vectorized

Returns

Return TypeMeaning
BootstrapResult.confidence_interval, .bootstrap_distribution, .standard_error

Sigmoid Function

Sigmoid

Formula

σ(z) = 1 / (1 + e−z)

Full Syntax

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# vectorized
sigmoid = lambda z: 1 / (1 + np.exp(-z))
np_sigmoid = lambda z: np.where(z >= 0, 1 / (1 + np.exp(-z)), np.exp(z) / (1 + np.exp(z)))  # numerically stable

Parameters

ParameterTypeDefaultPossible ValuesMeaning
zscalar, array-like—float, ndarrayInput (log-odds / linear combination)

Returns

Return TypeMeaning
float or ndarrayProbability in (0, 1)

Important Notes

  • Output range: (0, 1)
  • Use stable form for large |z| to avoid overflow
  • LogisticRegression: P(y=1|x) = sigmoid(x @ coef + intercept)
