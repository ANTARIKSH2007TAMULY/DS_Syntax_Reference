Sigmoid Function

Sigmoid

Formula

σ(z) = 1 / (1 + e−z)

Full Syntax

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# vectorized
sigmoid = lambda z: 1 / (1 + np.exp(-z))
np_sigmoid = lambda z: np.where(z >= 0, 1 / (1 + np.exp(-z)), np.exp(z) / (1 + np.exp(z)))  # numerically stable

Parameters

Returns

Important Notes
